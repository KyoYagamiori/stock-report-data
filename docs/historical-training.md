# 历史训练数据与日线试验

2026-11-11新增实际数据生产流程，不修改既有ChatGPT任务或日报时点。

## 执行和产物

运行 `python -m research_system.history_training`，依赖
`requirements-research.txt`、`requirements-history.txt`。
GitHub工作流 **Historical daily model pilot** 在本次代码/配置发布时触发，之后支持手动运行；
没有增加定时任务，也不自动移动历史截止日或最终留出期。

1. BaoStock免费公开接口查询2018-01-02历史名录，以固定种子按代码SHA-256排序抽取32只沪深主板股票。
   不使用今天的存续状态、名称、收益择样，不因采集失败替换股票，不能代表全市场。
2. 采集2017-01-01至2026-11-10未复权日线、当日ST/停牌字段、交易日历及沪深300指数。
   数据缓存可续跑，每份API字段返回封装为gzip并保存内容和压缩文件两个哈希。
   这些是捕获的API字段值，不冒充原始网络响应字节或交易所独立验收。
3. 用截至每一天的前收盘重置链构建因果价格连续序列，保留真实未复权成交价格。
   事件链仍需与分红送转原件核对；不下载含未来公司行动的最新前复权序列倒算历史。
4. 使用既有四类入口；同一股票、形态和原事件只采第一次，重叠形态按固定优先顺序留一条。
   以当日已完成日线假设16:00决策，下一交易日开盘尝试，不虚构历史真实发布时点。
5. 持有期从入场日记0，1/3/5表示之后相应交易日收盘退出，均满足日内不能卖出当日买入股票的约束。
   往返20bp为研究假设；收益扣同区间指数涨幅，不称真实账户收益。
6. 次日停牌、ST、一字或开盘接近涨跌停时判未成交，保留现金零暴露标签，不延迟到后来有利日期买入。
   退出缺行情、停牌或接近跌停的结果单列censored，禁止填零；它们使试验不能代表完整可交易策略。
   9.5%只是旧主板的保守过滤代理，不是官方逐日涨跌停价和委托成交审计。
7. 至少720个有样本特征日期才训练，最后120日锁定。Ridge与小型LightGBM滚动比较，
   按实际最晚标签结束日清除跨界样本；保留原早期规则和同候选池v1对照。
   最终选型只依开发验证，原始数据/模型/结果哈希绑定；完成的同一配置不重复试验最终留出期。

完整证据与训练结果：`output/history_pilot/`；简明状态：
`output/research/latest/history_pilot_status.json`，由既有research evaluation纳入summary。
`source_failures`逐码披露，`execution_counts`列未成交/退出不确定，覆盖不足不称全市场完成。
网络失败会保存具体原因和下一步，不能把“采集工作流运行”写成“模型已训练”。

## 试验和正式模型隔离

试验输入明确标记`scope=pilot`，只能显式按pilot接口训练。
默认正式入口拒绝该数据；不会生成`config/early_model_dataset.json`，不会降低既有正式验收标准。
试验训练成功状态为`trained_pilot_only`，正式状态仍为`not_trained`；两者分别呈现。

正式训练还需全历史时点名录、独立官方基准核对、公司行动事件核对、官方成交限制证据。
本试验市场相对特征采用指数，线上目前采用横截面中位数；因果价格口径与线上未复权字段也存在差别。
因此还必须验证线上/历史特征一致性，不能将试验权重直接用于日报推荐。
模型效果还需风险、不同市场阶段和前向运行检验，不承诺优于原规则，不输出上涨概率。

# 免账号历史数据与日线训练试验

2026-11-11：真实历史数据的研究试验已跑通。不修改既有ChatGPT任务、日报时点或正式推荐排序。

## 默认数据通道

默认采用微软Qlib文档推荐的社区数据仓库chenditc/investment_data公开发布包。
这是社区整理的数据，不是微软或交易所独立认证的数据。下载不需要数据账号或密钥。
原BaoStock采集器保留为可配置选项，网络失败有明确记录，不自动换源或混用缓存。

配置固定在config/history_training.json：发布标签2026-11-10；归档570942392字节；
SHA-256为47b62dab75cce922bb4d9086ed799bc212a3762ef796c04457030b04f4a68582。
同时核验发行清单、Dolt来源提交、Qlib代码提交、镜像摘要、实际归档字节及日历语义。
不能把哈希通过当成全部行情准确或模型有效。

从包内历史证券起止区间重建2018-01-02名单，固定种子按代码SHA-256抽取32只沪深主板股票。
保留后来退市股票；不按今天存续状态或未来收益择样，不因缺数替换股票。
采集2017-01-01至2026-11-10日线和沪深300指数。它是固定小样本，不代表沪深全市场。

Qlib归档使用float32。按其固定版本归一化代码重建未复权价格：price/factor；
成交量volume*factor*100转为股，金额amount*1000转为元，价格恢复A股分位。
原始所选二进制文件、元数据、转换字段和每层实际SHA-256均保存。
与腾讯未复权日线交叉核验固定样本前三只的最近30个重合日期，检查OHLC和成交量单位。
不匹配会阻止新训练；对方暂不可用则明确partial，不冒充已核验。
这项小样本交叉核验不代表全部历史准确，也不能验证ST状态或真实订单成交。

## 输入缺口和标签含义

归档没有历史ST字段。输入保留isST=unknown，不填成正常股票；仅显式price-only研究路径允许使用。
默认正式校验和普通成交判断仍拒绝未知ST状态。
缺价格日期不补成虚构停牌K线：次日无价格记未成交，退出缺价格记censored，分别保留证据。
观察到成交量不等于完成交易所停牌状态审计。
前收盘由归档因子链推导，保留其来源说明，不冒充交易所原始昨收；事件仍需独立核对。

重放既有四类早期布林入口；同一股票、形态、原事件只采首次，重叠形态按固定顺序留一条。
假设历史日线15:30已知、16:00决策，下一交易日开盘尝试；不是历史真实公开提示记录。
持有期从入场日记0，1/3/5指之后相应交易日收盘退出。
20bp往返成本和9.5%旧主板开盘过滤均为研究假设，未完成官方逐日涨跌停、ST和订单成交核对。
未成交保留现金零暴露标签；退出无法确认不填零，单列排除和删失偏差。
因此输出是带假设的价格收益标签，不能称真实可成交收益、账户收益或完整策略净值。

## 训练、复现和状态

运行：python -m research_system.history_training。
依赖requirements-research.txt与requirements-history.txt。
至少720个有合格样本的特征日期；最后120个有样本日期封存测试，
它们不一定是连续120个市场交易日。开发训练、验证、测试均按时间切分，
按实际最晚标签结束日清除跨界；同一配置的云端复现不计作新增独立试验。
Ridge与小型LightGBM按既有预登记规则比较，选择仅用开发验证，不根据最终留出结果改选。

Historical daily model pilot工作流在代码/配置发布或手动触发时运行，没有新增定时任务。
原始所选二进制、捕获数据、训练集、标签审计和模型结果保存到output/history_pilot/。
简明状态在output/research/latest/history_pilot_status.json，交叉核验在history_price_crosscheck.json。
既有research evaluation读取它们，区分正式模型与试验模型，并保留具体失败原因。
完成的固定配置复用结果时重新核对训练集、模型、标签审计和来源闭包的实际文件哈希。

训练成功仅记trained_pilot_only。正式状态仍可为not_trained；不创建正式训练集登记文件，
不自动替换日报推荐，不输出上涨概率。尚需完整历史股票池、ST、官方基准及成交限制核对、
线上/历史特征口径一致性、风险和前向观察等验收。
首轮结果尚不能证明成本后稳定改善；测试通过和模型训练成功不代表策略有效。

# 日报模型试运行

日线模型现在作为日报中可见的候选比较工具运行。模型排名、现有规则排名、VCP阶段和退出条件并排呈现，模型排名不能单独确认买点。试运行不等待收益模型正式晋级，但不把它描述为已经证明有效的收益预测系统。

## 读取入口

读取 `output/research/latest/daily_model_manifest.json`，再读取其指向的、符合当期截点的不可变 `output/research/daily_model/readers/*.json`。`daily`保存最近十个行情日期入口；当期截点以后才生成的版本不能冒充当期已知结果。缺少符合时点的版本时说明缺口，继续交付完整日报。

在原七节结构的第5节增加简短模型比较表：代码、机会阶段、模型/规则排名、报价时点、原预测时间、原有效期、防守/盈利保护条件。第7节增加试运行进展：唯一信号数、1/3/5日成熟数、模型与对照差异、未成交/未解决数。午报只引用已完成日线评分，盘中报价和触发确认另列，不能把日线模型说成11:30分钟模型。

综合首选继续核验催化、经营与风险；技术比较把模型排序作为一个输入，入场条件可以待触发或空缺。创业板和科创板保留原有研究和风险卡，本版模型不为它们补造评分。

## 使用现有库的数据

- 滚动日线库：逐文件与逐股票核验SHA-256，用于当前特征与后续价格标签；范围与条数每次实测披露。180根左右的滚动窗口不能冒充多年代数据。
- 当前初筛及特征档案：只取四池中最多80只候选，验证完成日线、代码、日期和来源；仅主板进入本版评分，日报最多展示10只。
- 多年代历史试验：复用原512只历史主板固定样本。训练和验证标签必须早于2026-01-20，之前看过的测试期不重新作为独立测试。
- 原日报文字：可以承接条件和公开时点，不凭文字回填成交或成功交易。

## 冻结模型与预测

LightGBM为固定试运行分支，Ridge和早期规则并行对照。删除历史/实时基准不同的相对市场字段，以及对复权尺度敏感的Alpha101常数项；VCP和其他无量纲量价字段沿用同一提取定义。历史因果复权与实时未复权的权益事件窗口仍需审计，不能声称已经完全解决口径一致性。

模型文件、数据集哈希和特征顺序冻结。相同模型、代码、形态和起源只登记一次，重跑保留原分数、原有效期和原条件卡。新版本不能覆盖旧预测。公开可用性在后续仓库读取时保守核验，无法证明模拟入场前已公开的记录不能进入前向成绩。

## 边运行边检验

BOLL日线筛选完成后唤醒模型。早报前和午间补验预测登记，20:47做晚报前兜底。午间采集和盘中发现的完成通知不再唤醒日线评分。历史强势股在15:47收盘后更新，20:47补查缺口。按实际运行时间判定数据可用性。

同一日线源、同一模型与候选特征复用评分。预测、反馈、覆盖或读者可见证据实质变化时再发行新版本。当天收盘后尚未有日线入口时记录等待，20:47后仍缺入口或已发布入口校验失败时保留明确异常。

按登记之后且预留30分钟发布时间的下一合格开盘价建立日线价格代理，1/3/5日按入场日之后的交易日结算，避免违反T+1。这是固定期限比较合同，不等于用户真实交易，也不等于按条件卡动态退出的收益。缺失行情、异常跳空、疑似无法退出的跌停和停牌保留未解决；不当作零收益或删除。

成熟样本进入 `output/research/daily_model/feedback/samples.jsonl.gz`。没有同口径基准、权益事件和成交证据时，只能形成价格代理表现，超额收益保持空值，不能直接混入正式训练集。未触发条件的观察卡不能计作真实成功交易。每周复盘模型与原规则、各形态及退出条件的差异；完成缺口审计后生成新的独立模型版本，保留原模型作前向对照。模型不在每次日报中重训，不反复利用同一已查看测试期调参。

正式晋级规则保持独立；其60日等门槛不阻止日报试运行，也不会因为运行天数达到门槛而自动晋级。

VCP独立历史候选集的下一轮研究见`docs/vcp-training.md`和
`output/research/latest/vcp_training_status.json`。它与本页已冻结的日报模型分开保存，
不扩大本版评分范围，不覆盖原模型、公开预测或旧日报。

## 自动重训

在 `config/daily_model.json` 启用 `automatic_retraining` 后，现有日线工作流结算完毕就会检查重训条件。
最新结果在 `output/research/latest/daily_model_retraining.json`，也随当期日线模型读取器发布。
从首个公开可核验的预测入场日累计前向交易日，按 `config/model_release_policy.json` 检查
60 个交易日、100 条新合格样本和 30 个新合格信号日。每只股票每个信号日只计一次。
早午报方向校准和买卖条件复盘继续分别计算。日线价格代理只用于研究反馈。

审核完成的公开市场回放结果按信号落在 `output/research/daily_model/feedback/audited/<signal_id>.json`。
记录须有 `schema_version=1`、`scope=audited_public_market_execution`、`signal_id`、
`prediction_sha256`、`entry_date`、`exit_date`、`label_known_at`、`benchmark_code`、
`gross_adjusted_stock_return_pct`、`gross_benchmark_return_pct`、`round_trip_cost_bps` 与 `evidence`。
`evidence` 中的 `official_benchmark`、`corporate_actions`、`execution_and_costs` 分别绑定
`audited/sources/` 下的证据文件及其 SHA-256。指数收益使用相同区间和统一指数口径。
执行证据须覆盖 T+1、日期对应的 ST、停牌、涨跌停、开盘与退出可成交性及费用。此入口接收已核验材料，
原始核验来源缺失时继续等待。只能写入公开市场证据。

达标后在按日期切分、隔离跨界标签的开发验证中比较模型和规则，再将 Ridge 与 LightGBM 冻结为新研究候选。
候选存于 `output/research/daily_model/retraining/`。文件实际发布后，随新信号冻结候选评分，
待同池入选对象的合格标签齐备后，与现行模型和早期规则对照。后续批次从候选上次纳入的最后信号日之后重新累计。
正式晋级须另行完成独立前向检验、成本、可成交性及风险审核，候选训练结果不会激活正式模型。

# 日报模型试运行

日线模型现在作为日报中可见的候选比较工具运行。模型排名、现有规则排名、VCP阶段和退出条件并排呈现，模型排名不能单独确认买点。试运行不等待收益模型正式晋级，但不把它描述为已经证明有效的收益预测系统。

## 读取入口

读取 `output/research/latest/daily_model_manifest.json`，再读取其指向的、符合当期截点的不可变 `output/research/daily_model/readers/*.json`。`daily`保存最近十个行情日期入口；当期截点以后才生成的版本不能冒充当期已知结果。缺少符合时点的版本时说明缺口，继续交付完整日报。

在原七节结构的第5节增加简短模型比较表：代码、机会阶段、模型/规则排名、报价时点、原预测时间、原有效期、防守/盈利保护条件。第7节增加试运行进展：唯一信号数、1/3/5日成熟数、模型与对照差异、未成交/未解决数。午报只引用已完成日线评分，盘中报价和触发确认另列，不能把日线模型说成11:30分钟模型。

综合首选继续核验催化、经营与风险；技术比较把模型排序作为一个输入，入场条件可以待触发或空缺。创业板和科创板保留原有研究和风险卡，本版模型不为它们补造评分。

## 使用现有库的数据

- 滚动日线库：逐文件与逐股票核验SHA-256，用于当前特征与后续价格标签；范围与条数每次实测披露。180根左右的滚动窗口不能冒充多年代数据。
- 当前初筛及特征档案：只取四池中最多80只候选，验证完成日线、代码、日期和来源；仅主板进入本版评分，日报最多展示10只。
- 多年代历史试验：复用原512只历史主板固定样本。训练和验证标签必须早于2026-01-20，之前看过的测试期不重新作为独立测试。
- 原日报文字：可以承接条件和公开时点，不凭文字回填成交或成功交易。

## 冻结模型与预测

LightGBM为固定试运行分支，Ridge和早期规则并行对照。删除历史/实时基准不同的相对市场字段，以及对复权尺度敏感的Alpha101常数项；VCP和其他无量纲量价字段沿用同一提取定义。历史因果复权与实时未复权的权益事件窗口仍需审计，不能声称已经完全解决口径一致性。

模型文件、数据集哈希和特征顺序冻结。相同模型、代码、形态和起源只登记一次，重跑保留原分数、原有效期和原条件卡。新版本不能覆盖旧预测。公开可用性在后续仓库读取时保守核验，无法证明模拟入场前已公开的记录不能进入前向成绩。

## 边运行边检验

上游完成后自动运行，并在早报前、午间、收盘后、晚报前补查。GitHub调度可能延迟，按真实执行时点披露。

按登记之后且预留30分钟发布时间的下一合格开盘价建立日线价格代理，1/3/5日按入场日之后的交易日结算，避免违反T+1。这是固定期限比较合同，不等于用户真实交易，也不等于按条件卡动态退出的收益。缺失行情、异常跳空、疑似无法退出的跌停和停牌保留未解决；不当作零收益或删除。

成熟样本进入 `output/research/daily_model/feedback/samples.jsonl.gz`。没有同口径基准、权益事件和成交证据时，只能形成价格代理表现，超额收益保持空值，不能直接混入正式训练集。未触发条件的观察卡不能计作真实成功交易。每周复盘模型与原规则、各形态及退出条件的差异；完成缺口审计后生成新的独立模型版本，保留原模型作前向对照。模型不在每次日报中重训，不反复利用同一已查看测试期调参。

正式晋级规则保持独立；其60日等门槛不阻止日报试运行，也不会因为运行天数达到门槛而自动晋级。

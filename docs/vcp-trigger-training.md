# VCP触发条件研究训练

2026-11-17完成第二轮固定研究候选 `vcp_triggered_daily_20261117_v1`。
读取`output/research/latest/vcp_trigger_training_status.json`及其绑定SHA-256的不可变证据。
复现命令为`python -m research_system.vcp_trigger_training`。本轮不替换日报在用模型，
不修改现有任务，不覆盖原预测或把结果倒填旧日报。

## 固定条件

复用历史原点512只主板样本来源，对其中392只股票的全部1006个首次形态观察重新建标签。
其中包括首轮因删失或期限不足未进入收益训练的21个形态，避免先按未来价格结果筛选样本。
2026-01-20及以后仍在复权、特征和结果计算之前排除，历史开发复盘不作为新的独立测试。

观察起点、枢纽价、失效低点、ATR和参考成交量按首次观察冻结。
最多等待3个完成日线收盘（包含首次观察当日），不因后续重跑重置。
收盘高于枢纽且全天量不低于冻结参考量1.5倍，才模拟次日开盘进入；
收盘先跌破冻结低点或超过枢纽0.5ATR就停止等待。
次日开盘超过枢纽0.5ATR、低于枢纽0.25ATR或不满足保守日线成交代理约束时，不模拟进入。
缺报价、缺观察或缺退出分别保留未解决，不能填成零收益。1/3/5日退出从入场日后计算，
不使用当日最高价反推盘中买到枢纽位，也不模拟入场当天卖出。

这些结果复用了已查看的历史开发区间，不据此选择最佳期限、松动触发阈值或自动切换模型。

# 明确卖出条件与模型实装要求

2026-11-13。取消旧“跌破中轨两天未收回就离场”的硬性要求。旧个人规则只保留作对照；
发现信号和卖出决策分别检验，不强制布林/KDJ/MACD始终占最高优先级。

## 参考框架与本项目参数

J LAW官方公开资料明确包含初始止损、风险回报比、止损不随意更改及只上调不下移等原则：
- https://www.jlawstock.com/glossary
- https://www.jlawstock.com/blog/20250903 （J Law Team署名）

下列数字均为本项目的研究假设，不是J LAW私有参数，也未验证为A股最优值：

| 条件 | 工具处理 |
| --- | --- |
| 入场前 | 给参考入场位、结构低点减0.25ATR的初始防守价，计算1R；初始结构风险超过8%提示放弃追入，不靠随意缩紧结构线凑风险 |
| 结构失效 | 触及原防守价优先考虑退出；计划一经登记不事后下移 |
| 早期VCP突破失败 | 前3个持有交易日收盘回落至枢纽价减0.25个初始ATR以下，产生退出条件 |
| 盈利保护 | 收盘盈利达到1.5R后，保护线取旧保护线、计入费用的保本价、最高已完成收盘减2ATR中的最高者；当天完成后才对下一根线生效 |
| 分批兑现 | 收盘达到2R，提出减持原仓位三分之一的参考条件；只有记录实际成交后才扣减仓位 |
| 时间效率 | 持有3个交易日后，最高已完成收盘仍未推进0.5R则提示复核，默认不强制卖出 |

R=真实或模拟入场价－初始防守价。没有真实入场价、入场日期和剩余仓位时，候选卡只提供
参考价格，不生成个人已持仓卖单，也不把参考入场价当真实成本。
结构防守、突破失败、盈利保护、分批兑现分别标明原因，触及上轨不自动卖出。

market_screen/exits.py提供create_plan、assess及record_fill。实际持仓参数只应在私有调用中使用，
公开队列保存的exit_plan始终是参考条件卡。首次公开的条件和时间保留，后续报告不重置。

## 历史回放及限制

python -m research_system.history_exits：读取已验收的同一512只训练试验及VCP模型，
对其滚动测试选择的同股票、同日期入场进行防守与盈利保护、机械时间止损、仅结构防守三个版本比较。
全部版本结果保留，不能从测试收益最高者倒推“最佳策略”。

退出决策只用当时已知的结构与已完成价格；当日新高不能反过来上调当日止损。
为避免假设盘中恰好按止损价成交，日线回放将已知触线或收盘条件执行在下一交易日开盘，
买入当日触线也不得当日卖出。第10日研究窗口末尾的清算只用于统一观察区间，不是实盘强制规则。
分批卖出按原仓位比例计费与计算基准；未知ST、逐日官方涨跌停、停牌和真实委托成交仍有缺口，
不可退出或缺价格的路径单列，不填成零收益或伪造成功退出。
这些是交易标签的研究比较，尚非包含重叠持仓、现金和完整逐日净值的可执行组合回测。

首轮机械时间止损回放没有改善平均净超额，故默认仅复核。结构及盈利参考可以展示；
未经验证的卖出参数不成为自动交易或“已验证最优卖点”。

## 什么时候实装

观察和退出参考卡可以先使用；预测排序晋级要通过config/model_release_policy.json中的预登记门槛：

1. 至少512只历史样本、720个开发特征日期且来源闭包可复核；样本数量本身不是有效性证明。
2. 在相同候选及成本口径下，20和40bp成本均值为正，净超额及相对原规则改善的日期块区间下限为正，至少60%的滚动段改善。
3. 拟实装范围的历史名录、官方基准、权益、ST/停牌/涨跌停、线上特征口径、T+1、跳空和组合资金/回撤有可追溯审计，未解决退出为0且回撤不劣于基线。
4. 退出规则本身通过成本、改善与可验证退出路径检查，不能仅凭入场模型成绩晋级。
5. 冻结模型后真实预登记前向预测，至少60个交易日、100个成熟信号及30个成熟信号日期，改善区间下限为正。20个交易日只检查运行，不是性能毕业条件。

以上数字是本项目的初步评审标准，不是普适充分样本量或收益保证。达到数量仍可能不合格。
以前已看过的测试区间不能重算成新独立测试；反复训练、挑最高历史收益也不等于可靠。
https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf

python -m research_system.history_release逐项输出passed/failed/missing，入口在
output/research/latest/model_release_status.json。没有已冻结模型的真实前向记录就标missing，
不能将旧观察名单、日历经过了多少天或事后回填当作预测模型前向验收。
通过只代表可评审有限范围的辅助排序，production_activation仍为false，不自动下单或直接替换全部推荐。

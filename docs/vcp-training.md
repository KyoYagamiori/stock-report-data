# VCP独立候选集训练

2026-11-17完成首轮研究候选版本 `vcp_independent_daily_20261117_v1`。
同日完成的触发条件研究训练另见`docs/vcp-trigger-training.md`；两个版本及原在用模型分开保存。
入口为 `output/research/latest/vcp_training_status.json`，其中的dataset、audits、models和result
均绑定不可变路径与SHA-256。复现命令为 `python -m research_system.vcp_training --workers 4`；
需先取回配置绑定的原始历史字段档案。已完成的同一实验只核验并复用结果，不反复训练成新测试。

## 样本与训练

沿用2018-01-02历史原点的512只主板固定样本，无替补，不以当前存活股票替换。
本次核验1,171,837条股票来源记录；在特征、复权或标签构建前排除2026-01-20及以后，
保留1,078,574根此前日线。独立检查959,660个股票日期的VCP结构，
不要求股票先进入布林线四个候选池。此范围不是沪深全市场。

相同股票和形态起点只保留首次合格观察，不以随后触发、成交或价格结果挑选观察日期。
低流动性、未完成期限和无法解决的退出分别保留统计；首次观察被删失后不能用后来的成功样本替代。
生成985个唯一形态，分布于602个信号日期；884个准备、67个接近枢纽、27个突破量能未确认、
7个收盘量能确认。后者不足以单独证明突破确认策略有效。

训练分别针对1、3、5日固定期限，每个期限保留Ridge和LightGBM，另设同池距枢纽规则对照。
使用固定756个交易日训练窗、126日验证窗、63日滚动段，并按实际标签结束日清除跨界标签。
最终训练492条、验证129条；训练标签截止2025-07-03，验证标签截止2026-01-15。
历史开发复盘有17段、394个有比较结果的信号日期，不能称新的独立测试。
不使用这些复盘结果挑选新的阈值、自动切换模型或提前计入前向成绩。

| 固定期限 | LightGBM相对同池规则的日均价格代理差（百分点） | 5交易日块重采样95%区间 |
| --- | ---: | ---: |

| 3日 | +0.0219 | -0.3033～+0.4238 |
| 5日 | +0.0624 | -0.3787～+0.5452 |

各区间均跨零，未建立稳定优势；Ridge的本轮点估计低于规则。
这是扣除20基点假定往返费用、减去供应商基准后的日线价格代理标签，
缺少交易所基准、历史ST、权益事件和真实成交审计，不能作为已核实的超额收益、胜率或组合净值。
观察后下一交易日开盘的标签，也不代表按VCP枢纽触发条件真实成交。

现有日报日线模型和公开预测保持原版本。VCP本轮模型仅保存为研究候选，
先核验历史因果复权与实时未复权的特征口径、权益事件、条件触发和成交约束，
再登记独立的固定前向候选；不得覆盖旧预测或回填旧日报。

## 完成日线评分入口修复

生产者的`early`角色在15:00后也会发布当日完成日线，角色名称不等于K线未完成。
日报模型读取器现允许`early`或`close`生产者，但必须同时满足：
当日15:00明确截点、截点后且不晚于读取时点的发布时间、全代码核算完整、零未解决代码，
以及候选记录的bar_date、last_bar、early_state和末个特征点同日。
午间和盘中覆盖层继续拒绝作为完成日线，模型本身未重训或替换。

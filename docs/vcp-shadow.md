## 在现有工具中的作用

布林带收口描述一段时间总体波动变小；VCP观察进一步检查多轮回调是否依次变浅、
低点是否抬高、末段整理是否缩量以及距离整理枢纽位还有多远。
VCP观察可独立于“刚收复中轨、首次回踩、收口预备、首次扩张”四类入口产生名单。
四类原排序不改，VCP不增加未经验证的预测权重，不输出上涨概率或直接下单建议。

market_screen/vcp.py中的所有数值均为本项目固定的待验证假设，不能归为J LAW原版或最优参数：
最多120根完成日线；局部高低点需要右侧两根已完成日线确认；至少两轮回调；
后一轮回调深度不超过前一轮80%，低点上移；所选第一高点至末低点至少14根日线；
首次回调不超过35%、末次不超过8%；最后五根振幅不超过8%；
最近五根成交量中位数不超过此前20根中位数75%；50日均线抬升且收盘在其上。
该50日背景检查不等同完整SEPA趋势模板，未伪造200日或行业相对强度。

当期计算使用截至前一日的冻结结构与枢纽位，当天新高不能反过来修改它。
输出准备、接近枢纽、盘中暂态突破、收盘量能确认、量能未确认、过度延伸、失效等阶段，
包含回调幅度序列、缩量比、枢纽价、结构低点、距枢纽ATR和数据时间。
距离突破位超过0.5 ATR标为延伸；结构低点仅是观察参考，不能保证A股T+1或跌停时止损成交。
盘中不将半天成交量与全天量直接相除，不把盘中突破称为收盘确认。

既有日报小队列增加独立vcp_shadow观察名单，最多10只；它是影子观察，不占用原15只排序名额。
当前模型验证目标仍是1/3/5日，不能把VCP中期整理案例的涨幅当作本系统短期收益证明。

## 相同样本的增量检验

python -m research_system.history_vcp：先核对已完成扩样试验的来源闭包，
再逐个股票、逐个特征日期回放VCP；特征函数只收到当日及以前的价格。
加入可计算标记、形态匹配、回调次数、末/首回调比、缩量比、距枢纽ATR、趋势背景7项。
各项特征的顺序写入模型，预测沿用同一顺序；缺结构时使用中性值与可计算标记。

基础模型与增强模型使用完全相同的样本、滚动切分、费用和已读区间排除规则。
配对比较每个测试信号日的结果，5个有信号日期为块估计不确定区间；
它们不是独立交易，也不是严格连续5个交易日。增量结果仅作描述，不据其调参、自动晋级。
还需独立研究完整VCP候选集、历史ST/涨跌停/权益事件、正式基准、组合重叠与实际交易约束。

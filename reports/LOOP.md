# 股票日报逐期闭环规则

本规则规定公开研究报告的流程。行情采集由既有 GitHub Actions 执行；日报直接读取快照、核验当期事实、比较候选、交付正文并归档。每期独立研判。2026-10-14 起采用以下候选比较规则，原全市场研究完成门槛停止适用，历史报告保持原样。

## 一期的输入和输出

1. 固定北京时间日期和类型，按交易所日历核验交易日。读取 `output/latest/manifest.json` 及本期 `report_readiness.selected_file` 不可变快照；核对日期、类型、来源、单位与时点。只有实际计算原始字节 SHA-256 并匹配 Manifest 才写哈希已验证。
2. 读取 `reports/latest/manifest.json` 和上一期实际归档正文。早报承接最近晚报，午报承接当日早报，晚报承接同日早午报；不能只看索引或读取后期报告。
3. 逐项验证前期判断、量价、关键价位、原窗口与失效条件，标为兑现、部分兑现、未兑现、待到期或无法验证，注明来源及实际时点；对错误判断作修正，不放宽失效门槛。
4. 选择活跃池 6—8 只，东威科技 688700 始终在池；其余从当前 Core/Watch 和经核对的新候选动态选择。根据前期验证、当期价量、新公告与产业证据、同业表现和风险记保留/新增/移出，不机械轮换。
5. 选择 3—5 张重点条件卡，东威必有。每卡包含来源、BOLL 与辅助指标、可比量价、判断、触发、期限与失效条件。固定研究标的不自动成为推荐。
6. 第 1 节点名本期唯一重点推荐，第 5 节写候选比较和推荐条件，第 7 节写代码、卡、判断、下一验证、原窗口、失效及来源时点。承接以正文为准。
7. 形成完整七节正文，直接在任务绑定的对话交付一条 final。依赖失败最多重试一次后换可靠源；无法补齐的字段列缺口。归档失败仍交付正文。不得只交链接或进度。
8. 按北京时间日期和类型去重，只有实际可见完整聊天正文算已交付，归档或触发成功不算。目标正文已归档但尚未聊天交付时，读取并交付同版；不要重复上传。

## 当期候选比较与唯一重点推荐

- 日报直接完成必要研究，不依赖其他研究任务、研究进度、后台状态或全市场逐股完成率。无需读取或写入持续研究检查点。
- 比较市场主线和竞争方向，区分短线、2—8周、6—24个月。事实注明当期可靠来源和发布时间，区分事实、推断、假设。候选范围据实际读取披露，不把采集池当全市场，不声称未经执行的全市场筛选或最优结论。
- BOLL 为主，KDJ/MACD 为辅。先观察收口/开口、中轨方向、沿上轨趋势及回踩承接；KDJ 采用相对位置、J 上穿/下穿，不机械套用 20/80。上升趋势收盘跌破中轨且两个完成交易日未收回，按既有条件判弱；不能下移旧失效位以延续判断。
- 至少横向比较 2—3 只可靠候选，选一只本期重点推荐。列名称和代码、胜出理由及其他候选不足、催化、核验行情、BOLL/量价、回踩或突破触发、当前条件是否满足、1—3交易日（重点当天/次日）、反方证据、降级及失效条件。
- 条件未触发仍可确定首选，明确等待条件，不能写成立即买入。推荐可沿用也可更换，必须说明证据；固定跟踪不等于固定推荐。
- 不以全市场筛选、基础档案或后台深研未完成为理由留空。若可靠候选全部不可交易或最低关键证据确实缺失，写具体原因，不编造股票、价格、新闻或胜率。
- 推荐字段采用 `focus_stock_code`，并记录 `focus_status` 为 `entry_condition_met`、`watch_for_trigger` 或 `data_unavailable`，另记 `research_method=candidate_comparison_boll_v1`。历史旧研究字段和报告不追溯改写；新报告不再展示研究累计完成率。

## 数据状态和恢复

- `ready_a` 仍须核对目标时点、技术口径及来源，不代表全部字段自动可信。
- `ready_b` 明确必要缺口，能从同一时点的可靠来源补齐则补齐。
- `not_ready`、旧日期、时间倒置或哈希不符拒用；最多重试一次后直接查交易所、公司公告和可靠行情源。不得用后来行情倒填早期截点。
- 早报行情使用最近完成交易日，资讯截至 09:00；午报行情严格 11:30，资讯 12:40；晚报当日收盘、资讯 21:00。休市日标注实际历史行情日期。
- BOLL(20,2,ddof=0)、KDJ(9,3,3，K/D 初值 50)、MACD(12,26,9，双倍柱)只用完成日线，注明参数、复权、单位及指标日期。未实际复算不能冒充更新，不宣称与其他软件完全一致。
- 午间量额只与上日同一完整上午比较，缺基线只列绝对量额；市场宽度和成交额说明沪深/媒体统计范围。
- 历史时点重建保留原截点并标注事后恢复，不能以午后值倒填午间。数据缺口不阻塞其余可靠内容的交付。

## 调度、归档与聊天交付

交易日北京时间 09:00、12:40、21:00；休市日早午静默、晚报继续。使用计划启动时点确定本期，提前最多 5 分钟、延迟不足 60 分钟可执行；合法启动后不能因研究结束较晚取消正文。常规不补过期报告、不增加尾盘提示。明确人工补发或发送验收按其指定要求执行。

仅公开归档公开行情研究、直接来源与无隐私承接摘要。不得上传个人持仓、成本、账户、交易记录、私人提示词、凭据或原始对话，不执行自动交易，不修改采集代码/配置/工作流。

归档路径为 `reports/archive/YYYY/MM/DD/{early|noon|evening}.md`。目标同版幂等成功，只有明确 404 才新建；不同版本核对后另存 revision，不静默覆盖。再以最新 blob SHA 增量合并 `reports/latest/manifest.json`，保留其他记录和历史，旧日期不覆盖较新指针。正文和索引回读一致才称已归档。写入或索引失败分别披露，聊天完整正文仍必须交付；归档与聊天交付分别验收。
